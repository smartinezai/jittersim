# Which browser modules `scripts/local-ci.sh --changed` runs for a changed file.
#
# One rule per line: a shell glob (a * also matches a /), then the modules it selects, or
#   all    every browser module
#   none   no browser module (the file cannot change what a browser module checks)
# A file may match several rules and gets the union. A file that matches no rule at all runs
# every browser module, so a new or unknown file can never silently skip coverage.
# A file tests/browser/<module>.py always selects <module> without a rule here.
#
# Keep these rules narrow and certain. This is a quick pre-check. The full `browser` run is
# what gates a pull request. tests/unit/test_local_ci.py checks that every module named here exists.
